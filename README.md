# 🎯 猜数字小游戏

一个使用 **Python** 编写的简单命令行小游戏。电脑会随机生成一个 **1 到 100** 之间的整数，玩家通过提示不断猜测，直到猜中为止。程序还会统计有效猜测的次数。

## ✨ 游戏功能

- 随机生成 1 到 100 之间的答案
- 根据猜测结果提示“**大了**”或“**小了**”
- 猜中后显示答案和猜测次数
- 输入无效内容时提示重新输入
- 限制猜测范围为 1 到 100

## 🧰 环境要求

- Windows
- Python 3

检查是否已安装 Python：

```cmd
py --version
```

如果命令无法识别，请先安装 Python，并在安装时启用 **Add Python to PATH** 选项。

## 🚀 如何运行

1. 打开命令提示符：按 `Win + R`，输入 `cmd`，然后按回车。
2. 进入项目文件夹：

   ```cmd
   cd /d D:\play_do\first
   ```

3. 运行游戏：

   ```cmd
   py guess_number.py
   ```

## 🎮 游戏玩法

根据提示输入一个 1 到 100 之间的整数：

- 猜测数字比答案大时，程序提示“**大了！**”
- 猜测数字比答案小时，程序提示“**小了！**”
- 猜中时，程序显示答案和猜测次数，游戏结束

只有范围内的有效整数会计入猜测次数。

## 🧠 程序逻辑

1. 使用 `random.randint(1, 100)` 随机生成答案。
2. 将猜测次数初始化为 `0`。
3. 使用 `while` 循环反复读取玩家输入。
4. 使用 `try/except` 检查输入是否为整数。
5. 判断猜测结果，并提示“大了”或“小了”。
6. 猜中后显示答案和次数，并用 `break` 结束循环。
